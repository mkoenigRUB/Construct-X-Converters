# Definition of Done

- [ ] Requirement and acceptance criteria linked to change
- [ ] Relevant skill(s) applied; design reviewed if UI changed
- [ ] Typecheck / lint / format checks passed or blockers recorded
- [ ] Unit/integration/E2E tests added as appropriate and actually run
- [ ] Negative cases, authorization and validation covered
- [ ] Loading, empty, error, keyboard and responsive states reviewed
- [ ] DB changes include migrations and rollback/backup considerations
- [ ] No secrets, debug statements or unnecessary personal data in logs
- [ ] Docs and deployment notes updated
- [ ] Human review before production deployment
